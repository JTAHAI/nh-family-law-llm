# Environment Namespace Migration

The active namespace is `NHFL_*`. At package import, the compatibility bridge maps a former variable only when its NHFL equivalent is absent. Explicit NHFL values always win. The bridge emits a `DeprecationWarning` and is planned for removal only through a documented future major release.
