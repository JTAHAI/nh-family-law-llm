# Privacy and security prelaunch review

Engineering controls preserve local-first matter separation, source grounding, human-review-required outputs, loopback gateway restrictions, and package scans for private data. Fixtures and sample material must remain synthetic; no case data, tokens, credentials, or personal screenshots belong in public evidence.

Still required for release evidence: real installed-app data-flow review, supported-user storage/backup/deletion checks, accessibility and lifecycle testing, and independent review of applicable policy/legal questions. The absence of these receipts is represented as `NOT_RUN` or `BLOCKED` by the canonical verifier, never as a privacy/security pass.
