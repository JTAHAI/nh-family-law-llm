# Store submission packet checklist

Prepared locally: unsigned r7 MSIX, static preflight receipt, listing draft, package identity template, icon/branding assets, and release blocker ledger. Do not submit this packet as-is.

Owner-dependent prerequisites: confirm the reserved Partner Center identity and publisher details; verify all public support/privacy URLs are owner-controlled; run WACK for the exact package; complete installed-package, accessibility, upgrade, uninstall, and clean-machine evidence; ensure legal review and authority gates are closed; then obtain separate authorization before any Partner Center submission. Microsoft signing/certification/publication are external outcomes and currently not run.
