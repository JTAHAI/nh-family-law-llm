# Pass 6 — New Hampshire legal behavior

Pass 6 converts the promoted NH core authority capsules into deterministic, source-gated issue spotting for parenting modification, child-support review, court-versus-DHHS support authority, and interstate jurisdiction triage.

Implemented controls include RSA 461-A:11 gate-first parenting analysis; child-specific RSA 461-A:6 evidence planning; separate schedule, decision-making, relocation, and enforcement routes; RSA 458-C modification/deviation audits; RSA 161-C issuer routing; UCCJEA triage; fail-closed UIFSA handling; noncompliance/guarantee drafting blocks; form-category verification; CLI and API interfaces; and generalized examples without private case facts.

This pass is not an attorney validation of the legal corpus, a child-support calculator, or a filing generator. It promotes no new authority.
